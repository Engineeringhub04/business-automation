OTP email flow
1. User ले signup गर्दा 6-digit code यही Gmail बाट "Business Automation" को नाममा जान्छ।
2. Code 10 मिनेट valid हुन्छ, 5 गलत प्रयास पछि block।
3. Settings मा email change गर्दा पनि नयाँ email मा code जान्छ।
4. App Password भनेको Gmail password होइन — Google Account → Security → 2-Step Verification → App passwords बाट 16 अक्षरको code बनाउनुहोस्।
